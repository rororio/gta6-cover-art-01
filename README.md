Vice Cover Studio — a fully offline web app that turns your photo and a caption into multi-panel GTA-style cover art with a Vice City sunset or neon grade, and exports it as a PNG in 1080×1080, 1080×1350 or 1920×1080.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick a layout, drop in a photo (or use the built-in samples), type a caption, and hit Export PNG.
